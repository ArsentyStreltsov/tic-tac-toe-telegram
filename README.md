# Бот для романтического свидания 💝

Этот бот поможет сделать ваше онлайн свидание более интересным и интерактивным!

## Функции бота:

- Викторина с вопросами о ваших отношениях
- Романтические задания
- Игра "Правда или Действие"
- Напоминания о том, что пора сделать перерыв и выпить

## Установка и запуск:

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` в корневой директории проекта и добавьте в него токен вашего бота:
```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
```

3. Запустите бота:
```bash
python bot.py
```

## Как использовать:

1. Найдите бота в Telegram по его username
2. Отправьте команду `/start`
3. Выберите, что хотите сделать:
   - Начать викторину
   - Получить романтическое задание
   - Начать игру

## Настройка вопросов и заданий:

Вы можете отредактировать списки вопросов и заданий в файле `bot.py`:
- `QUIZ_QUESTIONS` - вопросы для викторины
- `ROMANTIC_TASKS` - романтические задания
